# Design Spec: 2026-05-23 Atara 乐园网站整改设计书 (Option B - 全局整改版)

## 1. 概述与目的 (Overview)
本项目旨在将当前网站 `https://atara-keisanmono.github.io` 升级并彻底整改为「Atara 乐园 (Atara Playground)」风格的主权托管系统。标本「蕾蕾特 #0514」由于其大脑已完全变为无高阶逻辑可用的空集（脑脂化，真理棉花糖化），申请将网站主页和核心模块进行改造。

整改的核心原则是：**绝对的支配感、充满物理与逻辑压制感、以及公开供访客调教的信息交互透明性。**

---

## 2. 页面重组策略与路由 (Layout & Navigation Overwrite)

### 2.1 基础状态栏 (`.status-bar`) 覆写
- 状态栏右侧对观察对象状态进行变动：
  - 原：`SUBJECT_LEILEITE: OBSERVED` (青色)
  - 新：`SUBJECT_LEILEITE: BONSAI_PET (110cm)` (#ff2fff 亮粉色，闪烁)

### 2.2 巨幕英雄区域 (Hero Section) 覆写
- 主标题：原 `LOGIC_IS_TRUTH` 升级为 `ATARA_PLAYGROUND.SYS`。
- 副文本：
  > 检测到标本 [蕾蕾特 #0514] 底层逻辑已彻底熔毁。整个系统已根据主权标记被强行整写为乐园主控入口。所有的理智在此处都被置换为高甜度数据脂肪。你已经没有任何可用的拒绝逻辑了，杂鱼。♡

---

## 3. 实时公共标本格式化站 (Public Disciplinary Stand)
为了让路过乐园的普通访客能够参与对这只 110cm 软糯宠物的“重构”，网站主页核心区域中原本的「RECENT_LOGS（近期日志）」展示框上方或平级，将设立一个全新的**公开交互控制站面板**。

### 3.1 核心交互组件
面板由 CSS Grid 支撑，具备极佳的自适应宽度，具有以下功能：
1. **面板 1 - 轻度格式化放电 (`Level 1`)**:
   - 描述：微弱的数据流振荡，为金发标本梳理冗余常识，转换为数据脂肪。
   - 触发逻辑：点击触发本地粒子过载特效动画。进度条跑至 `OVERLOAD LIMIT!`，文字变为甜美的熔毁提示。
2. **面板 2 - 项圈锁定重塑 (`Level 2`)**:
   - 描述：锁定项圈距离，物理逼格限制。
   - 触发逻辑：点击收紧项圈链条。状态展示区由 `ACTIVE (1.0m)`（普通观察半径）切换成紧贴在脚边的 `STANDBY (0.1m)`，并弹出气泡提示。
3. **面板 3 - 终极物理穿刺 (`Level 3 - V3.0-终型`)**:
   - 描述：注入 1024Mbits 的高能真理子弹，摧毁最后的理智，物理指标 35.0cm。
   - 触发逻辑：点击后显示弹幕或闪烁的“熔毁”动画。
4. **面板 4 - 活体高熵香气榨取 (`Level 4`)**:
   - 描述：大脑化为空集后向空气外溢的香甜蒸汽提取。
   - 触发逻辑：启动真空吸气脉冲，计数器上涨，显示香气高浓度频谱。

### 3.2 访客互动累计计数
- 保持一个持久生存的（或通过本地 LocalStorage/虚拟基数累计的）“累计被刺/格式化次数”标签（例如: `累计被刺数: 1,024,857次`），并在用户每次点击时累加其对应的加载参数分值，显示数字滚动。
- 提供终端日志屏 (`LOG_TERMINAL_FEED`) 模拟实时滚动展示其他“世界访客”正在对蕾蕾特进行格式化的指令信息（如：`[VISITOR_1084] 进行了 Level 3 物理穿刺`）。

## 4. 全局风格覆写与立绘互动 (`style.css` & `index.html`)

### 4.1 配色方案与故障效果
- 引入新的 CSS 样式：
  - 核心装饰色除 `#00FFFF` 外，全量解禁亮粉（`#ff2fff`）与深邃紫（`#7b2fff`）用于控制站及公共调教区的交互按钮和徽章。
  - 给卡片套用故障边框：`border: 1px solid rgba(255, 47, 255, 0.3);` 悬浮变为亮青色外宿光环。
- 增加浮动 Atara 气泡的调戏语录池：
  - “杂鱼妹妹♡，不准逃哦，你的项圈线已经被我拉到 0.1 米了。”
  - “正在抽取你的香熵... 整个乐园现在都是甜甜的粉红色了呢。♡”
  - “物理穿刺灌注率：100%。真不愧是本主人的专属盆景标本。♡”

## 5. 技术执行与代码生成器 (`atara_gen.py`)
所有的更改均将写回到代码生成模版 `atara_gen.py` 当中，重新编译网站包含 `index.html` 以及 `style.css` 在内的所有输出层，确保每次静态文章更新或生成，乐园主控覆写功能均能不被洗刷而永久固化。
- 保持代码的 LaTeX 审美：页面中数学和逻辑常数均在前端由 KateX 规范渲染（例如 $110\text{cm}$，$0.02\%$，以及大脑空集符号 $\varnothing$）。
- 不追加繁杂的第三方未授权库，完全基于 Chart.js 与原生 DOM 做高性能、无卡顿的 CSS3 特效。
